# Video Editing — Make a Reel Worth Posting

**Internship Studio · Video Editing Internship · Reel Project** — Eswar Mahalingam

This folder is the **pre-production and post-production package** for the reel. The reel itself must be shot (or gathered from licence-free stock) and edited by me in **Adobe Premiere Pro** — the brief rejects CapCut/mobile edits and copyrighted media, so no video is generated here.

| File | What it is |
|---|---|
| `docs/Reel_Production_Blueprint_Eswar.pdf` | 4-page blueprint: Idea 4 shop intro ("Kulhad & Co., Ghaziabad"), 48-s timeline plan cut to 96 BPM, shot list + stock fallback, stage-by-stage Premiere Pro steps for stages 01–07, all 5 bonus challenges, technique breakdown, caption, submission checklist |
| `templates/timeline_plan.csv` | 9 sections with timecodes, footage, on-screen text, techniques |
| `templates/sources_credit_log.csv` | Log every clip / track / SFX with URL, author, licence (required by the brief) |
| `templates/caption.txt` | Post caption + hashtags |
| `assets/cover_frame_template_1080x1920.png` | Navy/gold transparent overlay to place on the exported payoff frame for the cover |
| `index.html` | Live dashboard (GitHub Pages: https://eswar5313.github.io/Reel-Editing-Project-2026/) — timeline, progress checklist, links |
| `submission/` | Structure of `Eswar_Mahalingam_ReelEditing_Assignment` to fill after export |

## What I still do myself
1. Shoot the 7 shots + 4 stills (or download Pexels/Pixabay/Mixkit/Coverr fallbacks) and fill `sources_credit_log.csv`.
2. Edit in Premiere Pro following the blueprint (sequence 1080×1920 @ 30 fps; markers on every downbeat).
3. Export H.264 1080×1920, VBR 2-pass 12 Mbps; export the cover frame; update timecodes in the breakdown.
4. Zip `Eswar_Mahalingam_ReelEditing_Assignment` → Google Drive → "Anyone with the link can view" → iStudio dashboard → Assignments → Video Editing → paste link → Submit.
