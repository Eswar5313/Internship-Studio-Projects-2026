## ▶️ How to run

```bash
# Python packs (01, 02, 03, 05, 06, 09, 10, 12, 16)
pip install pandas numpy scikit-learn matplotlib openpyxl jupyter
jupyter nbconvert --to notebook --execute --inplace 02-Data-Science/predictive_maintenance_final.ipynb

# C++ pack (04)
cd 04-CPP-Data-Structures && ./run_tests.sh        # g++ -std=c++17 -Wall -Wextra, every menu option, valgrind

# Web app (07)
cd 07-Web-Development-CartShare && python3 -m http.server 8080   # open in two tabs to see live sync

# AutoCAD pack (08) — regenerate the DXF/PDF/PNG set
cd 08-AutoCAD-Essentials && python3 build_drawings.py

# AWS pack (13) — run the gallery app locally
cd 13-AWS-Cloud/project1-ec2-s3-gallery && npm install && node app.js
```

Workbooks open in Excel or LibreOffice with all formulas live; every analytical sheet carries a **STEP-BY-STEP METHOD** block (step → what is done → cell → exact formula → result).

## ⚖️ Integrity notes

* **Declared substitutes.** Where a course file never reached the build — the AI pack's `video_telemetry.csv`, the Excel pack's Google Sheet, the AWS pack's Node.js zip — a clearly labelled synthetic or substitute stands in. Replace it with the official file and every formula, cell and chart updates; nothing is hand-typed.
* **Tools.** AutoCAD and Illustrator were unavailable, so drawings are DXF and artwork is SVG — both open natively in those tools. The Kaggle ML dataset is not redistributed; results come from the executed notebook's saved outputs.
* **Assumptions** (RCC loads and framing, HR statutory references, TechX budgets, marketing benchmarks) are stated at the top of each answer and never presented as measured data.
